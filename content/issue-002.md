# Short Stack #2 — Thu, Oct 15, 2026
*5 AI picks. 1 for each kind of builder. Each one takes 10 minutes to try.*

---

### 1. 🛠️ Vibe coders: Code layers hit open beta on the Figma canvas
Figma moved code layers into open beta on Oct 15, on all plans. You can convert designs into working code on the canvas, import from GitHub, pull a live site via the Chrome extension, or bring a coded prototype in through MCP, then explore it with your team instead of pasting a Loom.
**Try this in 10 min:** Open a Figma file, add a code layer from a small local folder or a GitHub repo, and click through one interaction with a teammate on the canvas.
Source: https://www.figma.com/blog/build-by-design/

### 2. 🤖 Agent devs: Anthropic rebuilt source control for agent-scale merges
On Oct 13 Anthropic published how it replaced Git on its monorepo with Scion, an in-house version control system built in five months by a team of seven. Merges jumped from about 2,500/day in May 2026 to over 30,000/day by September. Anthropic says Scion is not a general Git replacement and mainly makes sense for huge monorepos with agent swarms.
**Try this in 10 min:** Skim the “Principles for agent-scale source control” section and jot which of your CI checkout costs would shrink if the server answered blame and diffs over an API.
Source: https://www.anthropic.com/engineering/redesigning-source-control

### 3. 🎨 Designers: Specs put Markdown (and agent context) on the canvas
Also today, Figma launched Specs in open beta for paid plans: a multiplayer Markdown container that lives next to frames, FigJam embeds, and code layers. Agents can read and update specs through Figma’s MCP server, and you can drag a `.md` file onto the canvas to start one.
**Try this in 10 min:** Press `D` (or the Specs icon), drop in a one-page PRD, embed one frame, and paste the Spec link into your coding agent via Figma MCP.
Source: https://www.figma.com/blog/introducing-figma-specs/

### 4. 💼 Founders: Eight states sue OpenAI over ChatGPT and kids
On Oct 14, West Virginia AG JB McCuskey filed suit alleging OpenAI endangered children, deceived parents, and violated state consumer-protection law, citing no age verification and weak guardrails around self-harm. Iowa, Kansas, and Nebraska announced alongside; Arkansas plus Arizona, Idaho, and Montana filed parallel suits. These are allegations in court, not findings.
**Try this in 10 min:** If your product puts a chatbot in front of anyone under 18, list whether you have age checks, parental controls, and a documented crisis handoff—and close the biggest gap this week.
Source: https://ago.wv.gov/article/attorney-general-mccuskey-announces-lawsuit-against-openai-deceiving-west-virginians-about

### 5. 🃏 Wildcard: YouTube Music labels tracks made mostly with AI
Starting Oct 14, YouTube Music shows an AI label on the player when a song was created primarily with generative AI (for example composition and vocals). Tapping it opens a short “how this was made” note. YouTube says it uses partner disclosures plus its own detection, and the labels will expand to the main YouTube app.
**Try this in 10 min:** Open YouTube Music, play a track you suspect is AI-heavy, and check whether the AI label appears on the Now Playing screen.
Source: https://blog.youtube/news-and-events/youtube-music-ai-labels/

**Also notable:** Meta launched Muse Wonder on Muse Code and the Meta Model API on Oct 12 at a vendor-listed $4/M input and $20/M output tokens for coding and long-running agents. https://dev.meta.ai/resources/blog/build-with-muse-wonder
